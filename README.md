# ST-Copilot (fork)

This is an **unofficial fork** of the [ST-Copilot](https://github.com/Supker/ST-Copilot) SillyTavern extension (original author: QQ-Corporation / Quaren).

> ⚠️ **Install at your own risk.** This fork carries local, unreviewed modifications and is considered **unstable**. It is maintained for personal use and is not affiliated with the upstream project. Do not report fork-specific issues to the upstream repository.

Installation is the same as the upstream extension: clone or download this repository into `data/default-user/extensions/` and reload SillyTavern.
