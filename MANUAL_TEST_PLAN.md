- [ ] Чистый старт: `scp-clear-sessions` + перезагрузка страницы.

## 1. Установка и первый запуск

## 3. Подключение к модели
- [ ] `scp-conn-source`: ST Connection Profile ↔ Custom.
- [ ] `scp-conn-profile`: запросы идут через выбранный профиль ST.
- [ ] Custom: `scp-custom-url` + `scp-custom-key` + `scp-custom-model`; неверный ключ → понятная ошибка.
- [ ] `scp-max-tokens` уважается.
- [ ] Стриминг `scp-st-stream-auto/on/off`: во всех режимах ответ дописывается до конца, reasoning рендерится инкрементально без дублей.
- [ ] Отмена генерации — чистое прерывание, без зависшего спиннера.

## 4. Контекст и промпт
- [ ] `scp-include-sysprompt`, `scp-include-persona`, `scp-include-hidden-msgs`, `scp-include-alt-swipes` — каждый влияет на собираемый контекст.
- [ ] `scp-auto-expand-macros` — {{user}}/{{char}} подставляются.
- [ ] `scp-history-limit` — обрезка истории (поставить 5 → в контексте 5 сообщений).
- [ ] `scp-reasoning-trim` — reasoning вырезается из контекста.
- [ ] `scp-apply-regex` — regex-скрипты ST применяются.
- [ ] Блоки карточки `scp-ce-*` (description, personality, scenario, first_mes, mes_example, authors_note, system_prompt, post_history, alt_greetings + picker) — каждый добавляется/исключается; выбранный alt greeting подставляется.
- [ ] `scp-sysprompt` редактируется; `scp-reset-prompt` возвращает дефолт.

## 5. Профили и байндинги
- [ ] CRUD профилей: `scp-profile-create-new / duplicate / rename / delete / save`; `scp-profile-select` переключает все настройки.
- [ ] `scp-bind-char` — профиль подхватывается при выборе персонажа.
- [ ] `scp-bind-chat` — приоритет chat > char > дефолт.
- [ ] Переименование/удаление привязанного профиля — корректный fallback, байндинги не ломаются.

- [ ] Длинный стрим: инкрементальный рендер не дёргает скролл; ручной скролл вверх отключает автоскролл.

## 16. Ошибки и граничные случаи
- [ ] Сетевой сбой (API выключен) → сообщение об ошибке, retry, состояние чата цело.
- [ ] Пустой ответ / обрыв стрима.
- [ ] Чат 200+ сообщений + perf-mode — без фризов UI.
- [ ] Быстрое переключение чатов/персонажей во время генерации — ответ не попадает «не в тот» чат.
- [ ] Спецсимволы/HTML/код-блоки — рендер без XSS.
- [ ] Окно настроек ST + окно Copilot одновременно — z-index, фокус.
